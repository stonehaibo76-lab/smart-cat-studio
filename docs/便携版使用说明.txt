Smart-CAT Studio V1.8.3.1 — 便携版使用说明
========================================

一、快速开始
------------
1. 将整个 zip **解压到一个普通文件夹**（建议路径不含中文空格，且不要放在百度网盘等同步目录）。
   解压后应直接看到 runtime、dist、Start-SmartCAT.bat（不要多一层空壳目录）。
2. 双击 **Start-SmartCAT.bat** 一键启动（亦可用 Smart CAT Studio.bat，效果相同）。
3. 等待控制台显示「Smart-CAT Studio 已运行」，浏览器会自动打开 http://127.0.0.1:58741
4. 关闭控制台窗口即可停止全部服务。

二、包含功能
------------
- 本地 SQLite 数据库（项目、记忆库、术语库、孪生译员等）
- Okapi 侧车：DOCX / PPTX / HTML / TXT 等格式导入与原文格式导出
- MT 参考引擎：编辑器内多引擎机器翻译对照（需联网）
- 孪生译员：个性化翻译建议（需配置 AI API Key）

本便携版不包含「向量检索 / 知识库向量化」功能。

三、首次使用建议
----------------
1. 打开「系统设置 → AI 引擎」，填写 Gemini 或 DeepSeek API Key（孪生译员与 AI 建议需要）。
2. MT 参考默认已启用（127.0.0.1:8770），可在「系统设置 → MT 参考」中测试连接。
3. 数据库默认保存在本目录 data\smartcat-local.db，可在「系统设置 → 本地数据」查看路径、导出备份。

四、数据备份与迁移
------------------
- 复制 data\smartcat-local.db 到 U 盘或新电脑同目录即可迁移。
- 或在应用内「本地数据 → 导出数据库」下载 .db 文件。

五、常见问题
------------
Q: 双击 bat 后提示端口占用？
A: 确认未重复启动；或检查 58741 / 8090 / 8770 是否被其他程序占用。

Q: MT 翻译失败？
A: MT 引擎依赖第三方网站，需联网，且不保证 100% 可用；可换其他引擎试试。

Q: 杀毒软件拦截？
A: 便携包内含 Node / Python 运行时，可能被误报；请将解压目录加入信任列表。

Q: better-sqlite3 报错？
A: 勿将程序放在云同步文件夹；若从旧目录迁移，请完整复制整个文件夹。

七、发版前验证清单（维护者）
----------------------------
[ ] 在未安装 Node / Python 的干净 Windows 10/11 解压 zip，双击 bat 可打开编辑器
[ ] 新建项目并导入 DOCX 或 PPTX（Okapi 8090）
[ ] 编辑器 MT 参考面板可查询（8770）
[ ] 孪生译员创建档案并生成建议（已配置 API Key）
[ ] 重启后 data\smartcat-local.db 数据仍在
[ ] 设置页无「向量检索」；知识库页无「重算向量」按钮

八、构建便携包（维护者）
------------------------
在项目根目录执行：
  npm run build:portable

若 node_modules 已完整，脚本会跳过 npm ci（避免百度云盘等同步目录锁定 esbuild.exe）。
打包前请关闭「启动Smart CAT Studio」开发窗口（npm run dev / server）。
若必须重装依赖：npm run build:portable -- --fresh

输出：release\Smart-CAT-Studio-1.8.3.1-portable-win64.zip
